# Instalacion de Control Muestras LENC

Para instalar el programa en otro computador, comparta este archivo:

`dist/installer/ControlMuestrasLENC-Setup-Usuario.exe`

Ese es el instalador actual para usuarios finales. No es necesario compartir la carpeta `dist/ControlMuestrasLENC`, el archivo `.zip` portable, `target`, `out` ni archivos antiguos con nombres de prueba.

Para que la actualizacion automatica funcione, en la carpeta compartida de actualizaciones deben existir:

`ControlMuestrasLENC-Setup-Usuario.exe`
`latest.properties`

La carpeta local usada actualmente para publicar actualizaciones es:

`C:\Users\ades1\OneDrive\bd_nyce\actualizaciones`
